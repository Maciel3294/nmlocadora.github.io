NM LOCADORA — SITE ATUALIZADO

Esta versão mantém a estrutura do site anterior, mas melhora principalmente:
- espaçamento lateral e largura do conteúdo, evitando sensação de "zoom";
- logo real da NM;
- imagens reais enviadas para o catálogo;
- galerias por categoria com visualização ampliada;
- nomes das categorias preparados para crescer;
- área de atendimento/regiões;
- visual mais corporativo e alinhado a construção civil, infraestrutura e saneamento;
- formulário que monta a mensagem e abre o WhatsApp da NM.

Categorias com fotos nesta versão:
- Betoneiras — 2 fotos
- Andaimes — 2 fotos
- Compactadores de solo a gasolina — 3 fotos
- Geradores a gasolina — 2 fotos
- Marteletes rompedores elétricos — 4 fotos

Serras Clipper e Placas vibratórias ficam como espaços preparados para receber as fotos reais quando forem enviadas.

Para publicar gratuitamente, use GitHub Pages, Cloudflare Pages ou outro serviço de hospedagem estática.
